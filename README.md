# ♻️ RRR – Reduce, Reuse, Recycle

**Small Actions, Big Impact 🌍**

RRR is an AI-powered sustainability platform connecting **individuals, NGOs, and EcoRecycler partners** to promote environmental responsibility through community-driven action.

## 🚀 Key Features

* 🌱 **Reduce** – Climate news, eco tips, carbon calculator, events, and weekly challenges
* 🔄 **Reuse** – Community marketplace for sharing reusable items
* ♻️ **Recycle** – Connect with verified recycling centers and collection partners
* 🍲 **Food Share** – NGO-based surplus food sharing
* 🏆 **Gamification** – Eco badges, challenges, and community leaderboard
* 👤 **Profile** – User profiles, achievements, and challenge history
* 🤖 **AI Insights** – Gemini-powered environmental content and recommendations

## 🛠️ Tech Stack

* **Frontend:** React 18, TypeScript
* **Styling:** Tailwind CSS
* **Build Tool:** Vite
* **AI:** Google Gemini AI
* **Backend & Database:** Supabase
* **Routing:** React Router
* **Version Control:** GitHub

## 🎯 Objective

* Reduce environmental impact
* Promote reuse and recycling
* Prevent food waste
* Connect communities with NGOs and recyclers
* Encourage sustainable lifestyles

## ⚙️ Getting Started

```bash
git clone <repository-url>
cd RRR
npm install
npm run dev
```

For production:

```bash
npm run build
npm run preview
```
